✨ Возможности

Все, что нужно для ухода за растениями

PlantCare объединяет передовые технологии ИИ с удобным интерфейсом для максимально эффективного ухода за вашими растениями

🤖

AI-ассистент (Groq API)

Мощный ИИ-помощник на базе Groq API (Llama 3.1/3.2) с автоматическим fallback на Gemini и локальную базу. Отвечает на вопросы по уходу за растениями, анализирует фото и даёт персональные рекомендации.

📸

ИИ-анализатор растений

Сделайте фото растения и получите подробный анализ: определение вида, оценка здоровья, выявление проблем и рекомендации по уходу. Использует Groq Vision и Gemini для максимальной точности.

🏥

Диагностика болезней

Обнаруживайте проблемы со здоровьем растений на ранних стадиях. Локальная база заболеваний + AI-диагностика по симптомам с пошаговыми рекомендациями по лечению.

🔍

Расширенный справочник

Справочник растений с описаниями, требованиями к уходу и изображениями. Локальная база + Perenual API (300K+ растений) + Pixabay для фото. Данные доступны оффлайн.

💡

Персональные рекомендации

Получайте индивидуальные советы по поливу, освещению, удобрениям и пересадке с учетом конкретного вида растения и условий содержания.

🌐

Оффлайн режим

Все основные функции работают без интернета. AI-ассистент автоматически переключается на локальную базу при отсутствии подключения. Ваши данные остаются конфиденциальными.
