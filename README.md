# 🌱 PlantCare Website

**Официальный сайт для скачивания приложения PlantCare**

Современный одностраничный сайт с максимальным дизайном для распространения релизов приложения PlantCare.

---

## ✨ Особенности

- 🎨 **Красивый дизайн** — современный UI/UX с анимациями и градиентами
- 🌓 **Темная/светлая тема** — автоматическое переключение с сохранением настроек
- 📱 **Адаптивный дизайн** — идеальная работа на всех устройствах
- 🚀 **Быстрая загрузка** — оптимизированный код, минимальные зависимости
- 🎯 **SEO-оптимизация** — правильная структура для поисковых систем
- ♿ **Доступность** — семантический HTML, поддержка навигации с клавиатуры
- 🎉 **Интерактивность** — плавные анимации, 3D эффекты карточек
- 📊 **Отслеживание скачиваний** — логирование в консоль (можно расширить)

---

## 📁 Структура проекта

```
PlantCare-Website/
├── index.html              # Основная HTML структура
├── styles.css              # Премиум CSS дизайн с темами
├── script.js               # Интерактивный JavaScript
├── generate-downloads.js   # Генератор downloads.json (Node.js)
├── downloads.json          # Автогенерируемый список релизов
├── README.md               # Документация (этот файл)
```
